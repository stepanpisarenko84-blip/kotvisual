KOT CLIENT - визуальный HUD для Forge 1.16.5 (только оформление, без читов).

СБОРКА (GitHub):
1. Создай новый репозиторий, загрузи в него СОДЕРЖИМОЕ этой папки (вместе со скрытой .github).
2. Actions -> Build mod -> дождись зелёной галочки.
3. В разделе Artifacts скачай kotclient-jar -> kotclient-1.0.jar, положи в .minecraft/mods.

ЧТО ВНУТРИ:
  Watermark    - Kot Client, ник, ping, время (слева сверху)
  Inventory    - панель с твоим инвентарём (слева)
  Hotkeys      - список модулей и их клавиш (справа)
  Active potions, Cooldowns - сверху по центру
  Target HUD   - ник, голова и HP существа, на которое смотришь

Каждый модуль включается/выключается клавишей: Настройки -> Управление -> Kot Client
(по умолчанию клавиши не назначены).

НАСТРОЙКИ (цвета и позиции) - в начале KotClient.java.
